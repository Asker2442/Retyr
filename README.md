# ИИ-агент поддержки и продаж для Telegram

Бот на Claude, который:
- отвечает клиентам по базе знаний компании (`knowledge.md`);
- консультирует и подводит к покупке или записи;
- собирает заявки (имя, телефон, запрос), сохраняет их в `leads.jsonl` и сразу присылает вам в Telegram;
- зовёт живого менеджера, если вопрос сложный или клиент недоволен.

## Запуск за 5 минут

1. **Создайте бота.** В Telegram откройте @BotFather, отправьте `/newbot` и скопируйте токен.
2. **Получите ключ Claude API** на https://platform.claude.com/settings/keys (нужен баланс на счёте).
3. **Установите зависимости** (Python 3.10+):
   ```bash
   python -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   ```
4. **Настройте `.env`:**
   ```bash
   cp .env.example .env
   ```
   Впишите `TELEGRAM_BOT_TOKEN` и `ANTHROPIC_API_KEY`.
5. **Запустите:** `python bot.py`
6. Напишите боту `/chatid`, впишите полученное число в `OWNER_CHAT_ID` в `.env` и перезапустите бота. После этого заявки будут приходить вам.

## Как продавать это бизнесу

Под каждого клиента меняется только `knowledge.md`: услуги, цены, адрес, FAQ, акции.
Код остаётся тем же. Один шаблон можно продавать салонам, клиникам, автосервисам, школам, интернет-магазинам.

Варианты цены: настройка от 15–30 тыс. ₽ и абонентская плата 3–10 тыс. ₽ в месяц (хостинг, правки базы, поддержка).

## Что доработать для продакшена

- **Хостинг 24/7.** VPS (от ~300 ₽/мес) с запуском через `systemd`/`docker`, иначе бот работает, только пока открыт ваш компьютер.
- **База данных.** История диалогов сейчас хранится в памяти и сбрасывается при перезапуске. Можно заменить на SQLite или Redis.
- **CRM.** В `run_tool` → `save_lead` можно отправлять заявку в amoCRM, Bitrix24 или Google Таблицы.

## Стоимость работы

Используется модель `claude-opus-5-5` с низким уровнем размышлений (`effort: low`), база знаний кешируется.
Можно переключить на более дешёвую модель через `CLAUDE_MODEL=claude-haiku-5-5` в `.env`.
